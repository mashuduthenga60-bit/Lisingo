Class Responsibility Collaborator (CRC) Cards

Lisingo C2C E-Commerce Platform

User
Responsibilities
  • Register and login
  • Manage profile information
  • List products for sale
  • Browse and search products
  • Add items to cart
  • Place orders (buy)
  • Send/receive messages
  • Leave reviews for sellers
Collaborators
  • Product
  • Order
  • Cart
  • Message
  • Review
  • Role
Product
Responsibilities
  • Store product details (title, description, price)
  • Track product condition (new/used/refurbished)
  • Manage product images (up to 4)
  • Track stock quantity
  • Track view count
  • Manage product status (active/sold/pending/removed)
Collaborators
  • User (Seller)
  • Category
  • Order
  • Cart
  • Review
  • Message
Order
Responsibilities
  • Record transaction between buyer and seller
  • Store order quantity and total price
  • Track order status (pending to delivered)
  • Store shipping address
  • Record payment method
  • Update product stock on purchase
Collaborators
  • User (Buyer)
  • User (Seller)
  • Product
Category
Responsibilities
  • Classify products into groups
  • Support parent-child hierarchy (subcategories)
  • Store category name and description
  • Provide filtering for product browsing
Collaborators
  • Product
  • Category (self - parent)
Cart
Responsibilities
  • Store items user intends to buy
  • Track quantity per item
  • Allow add, update, remove operations
  • Calculate subtotals and totals
  • Prevent duplicate entries
Collaborators
  • User
  • Product
  • Order (at checkout)
Role
Responsibilities
  • Define user types (super_admin, admin, moderator, user)
  • Control access to admin features (RBAC)
  • Store granular permissions per role
  • Enforce authorization checks
Collaborators
  • User
  • Admin Panel
Message
Responsibilities
  • Enable buyer-seller communication
  • Store message content and timestamps
  • Track read/unread status
  • Link messages to specific products
Collaborators
  • User (Sender)
  • User (Receiver)
  • Product
Review
Responsibilities
  • Store seller ratings (1-5 stars)
  • Store review comments
  • Link reviews to specific products
  • Calculate average seller ratings
Collaborators
  • User (Reviewer)
  • User (Reviewed Seller)
  • Product
